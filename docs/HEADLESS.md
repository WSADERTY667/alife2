# Headless-режим симуляции ALife MVP

## Описание

Headless-режим позволяет запускать симуляцию без графического интерфейса (Pygame) для:
- Автоматизированного тестирования
- Сборки статистики
- Интеграции с внешними системами
- Запуска на серверах без дисплея

## Использование

```bash
python main.py --headless [OPTIONS]
```

### Параметры командной строки

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|--------------|----------|
| `--headless` | flag | - | Запустить в headless-режиме |
| `--seed` | int | None | Seed для генератора случайных чисел (воспроизводимость) |
| `--ticks` | int | 1000 | Количество тиков симуляции |
| `--agents` | int | None | Начальное количество агентов (переопределяет config) |
| `--food` | int | None | Максимальное количество еды (переопределяет config) |
| `--hidden-neurons` | int | None | Количество скрытых нейронов в мозге агента |
| `--out` | str | None | Путь к выходному JSON-файлу с результатами |

### Примеры

```bash
# Базовый запуск на 1000 тиков
python main.py --headless --ticks 1000

# Воспроизводимый запуск с seed
python main.py --headless --seed 42 --ticks 1000

# С выводом результатов в JSON
python main.py --headless --seed 42 --ticks 1000 --out results.json

# С кастомными параметрами
python main.py --headless --seed 42 --ticks 5000 --agents 50 --food 200 --out run.json
```

## Формат выходного JSON

При указании параметра `--out` результаты симуляции сохраняются в JSON-файл со следующей структурой:

```json
{
  "seed": 42,
  "ticks": 1000,
  "agent_count": 25,
  "births": 1,
  "deaths": 0,
  "avg_generation": 0.04,
  "food_count": 90,
  "agents": [
    {
      "id": 1,
      "generation": 0,
      "x": 640.1265869140625,
      "y": 418.6622009277344,
      "energy": 88.61789853215106,
      "hormones": {
        "D": 0.3293421082171523,
        "S": 0.9022940498051186,
        "O": 0.5139469572240051,
        "C": 0.30420675818041615,
        "T": 0.5353111128322781
      },
      "depression": 0.0,
      "breakdown": 0.0
    }
  ]
}
```

### Поля верхнего уровня

| Поле | Тип | Описание |
|------|-----|----------|
| `seed` | int | Seed, использованный для инициализации RNG |
| `ticks` | int | Количество выполненных тиков симуляции |
| `agent_count` | int | Количество агентов в конце симуляции |
| `births` | int | Общее количество рождений за симуляцию |
| `deaths` | int | Общее количество смертей за симуляцию |
| `avg_generation` | float | Среднее поколение агентов |
| `food_count` | int | Количество единиц еды в конце симуляции |
| `agents` | array | Массив данных об агентах |

### Поля агента

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | int | Уникальный идентификатор агента |
| `generation` | int | Поколение агента (0 = начальный) |
| `x` | float | X-координата позиции |
| `y` | float | Y-координата позиции |
| `energy` | float | Текущий уровень энергии |
| `hormones` | object | Уровни гормонов |
| `depression` | float | Уровень депрессии (0.0–1.0) |
| `breakdown` | float | Уровень психического срыва (0.0–1.0) |

### Поля гормонов

| Поле | Описание |
|------|----------|
| `D` | Дофамин (вознаграждение, мотивация) |
| `S` | Серотонин (настроение, благополучие) |
| `O` | Окситоцин (социальность, доверие) |
| `C` | Кортизол (стресс, тревожность) |
| `T` | Тестостерон (агрессия, доминирование) |

## Вывод в консоль

После завершения симуляции в консоль выводится краткая статистика:

```
=== Headless Simulation Results ===
Ticks completed: 1000
Average tick time: 17.732 ms
Final agent count: 25
Average generation: 0.04
Total births: 1
Total deaths: 0
Total simulation time: 18.31 s
Results written to: out_py.json
```

## Примечания

- Симуляция не изменяется ради формата вывода — JSON содержит только снимок состояния в конце
- При отсутствии `--out` результаты выводятся только в консоль
- Для воспроизводимости всегда используйте `--seed`
- Если агенты погибают во время симуляции, они не включаются в итоговый JSON
