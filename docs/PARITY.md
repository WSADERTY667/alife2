# Parity Tool: Сравнение Python и C++ симуляций

## Назначение

Инструмент `tools/compare_python_cpp.py` предназначен для сравнения результатов работы Python и C++ версий симуляции ALife MVP. Он позволяет убедиться, что обе реализации ведут себя одинаково при одинаковых начальных условиях.

## Установка и запуск

### Генерация выходных данных

Сначала необходимо запустить симуляцию на обеих платформах с одинаковыми параметрами:

```bash
# Запуск Python симуляции
python python/main.py --headless --seed 42 --ticks 1000 --out out_py.json

# Запуск C++ симуляции
./build/alife_headless --seed 42 --ticks 1000 --out out_cpp.json
```

### Сравнение результатов

```bash
python tools/compare_python_cpp.py out_py.json out_cpp.json --pos-tol 1e-3 --value-tol 1e-3
```

## Параметры командной строки

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `py_output` | JSON файл с результатами Python симуляции | - |
| `cpp_output` | JSON файл с результатами C++ симуляции | - |
| `--pos-tol` | Допуск для сравнения позиций агентов | `1e-3` |
| `--value-tol` | Допуск для сравнения числовых значений (энергия, гормоны и т.д.) | `1e-3` |

## Сравниваемые метрики

Инструмент сравнивает следующие параметры:

### Скалярные значения
- **agent_count** — итоговое число агентов
- **births** — общее число рождений
- **deaths** — общее число смертей
- **avg_generation** — среднее поколение агентов
- **food_count** — число единиц еды

### Позиции агентов
- Координаты X и Y каждого агента (с учётом допуска `--pos-tol`)

### Свойства агентов
- **energy** — энергия агента
- **hormones** (D, S, O, C, T) — уровни гормонов
- **depression** — уровень депрессии
- **breakdown** — уровень breakdown

> **Примечание:** Гормоны, depression и breakdown сравниваются только если они присутствуют в обоих файлах.

## Формат вывода

### Успешное сравнение (PASS)
```
PASS
```

### Обнаружены расхождения (FAIL)
```
FAIL

Найдено расхождений: N
  - описание первого расхождения
  - описание второго расхождения
  ...
```

## Примеры

### Пример PASS

```bash
$ python tools/compare_python_cpp.py out_py.json out_cpp.json --pos-tol 1e-3 --value-tol 1e-3

```

### Пример FAIL


## Рекомендуемые допуски

Для стандартных MVP-параметров рекомендуется использовать:

- `--pos-tol 1e-3` — для позиций
- `--value-tol 1e-3` — для значений

При необходимости можно увеличить допуски для компенсации различий в точности вычислений между Python (float64) и C++ (float).

## Интеграция в CI/CD

Инструмент возвращает код выхода:
- `0` — PASS (расхождений нет)
- `1` — FAIL (обнаружены расхождения)

Это позволяет использовать его в автоматических тестах:

```bash
python tools/compare_python_cpp.py out_py.json out_cpp.json && echo "Tests passed" || echo "Tests failed"
```

## Ограничения

- Инструмент не должен менять симуляцию ради достижения parity
- Расхождения не скрываются, а явно выводятся
- Временные файлы `out_py.json` и `out_cpp.json` не должны коммититься в репозиторий
